# ПРОЕКТ: AI AUTO CLIPPER / AI VIDEO EDITOR

## 1. ЦЕЛЬ ПРОЕКТА

Создать собственный автоматизированный AI-сервис для обработки длинных видео, Twitch VOD, YouTube-видео и локальных файлов.

Система должна получать длинное видео и самостоятельно:

1. анализировать видео и аудио;
2. распознавать речь на русском и других языках;
3. определять интересные моменты;
4. самостоятельно определять начало и конец каждого интересного момента;
5. удалять тишину, паузы, пустые участки, загрузки, повторы и другие ненужные фрагменты;
6. создавать вертикальные ролики 9:16 для TikTok / YouTube Shorts / Instagram Reels, которые потенциально станут вирусными и наберут максимум просмотров;
7. автоматически выбирать область кадра, работать с вебкамерой;
8. создавать красивые субтитры с таймкодами отдельных слов;
9. создавать длинные компиляции примерно 10–30 минут для YouTube;
10. генерировать название;
11. генерировать описание;
12. генерировать хэштеги;
13. в перспективе автоматически публиковать контент на соответствующие платформы (низкий приоритет);
14. в перспективе анализировать статистику опубликованных роликов и использовать ее для улучшения выбора моментов.
15. в перспективе сделать сервис публичным, с доступом по подписке (приоритет средний)

Главная идея:

> Создать не просто "нарезчик видео", а полноценного AI-монтажера, который может получить 5–10 часов стрима и самостоятельно превратить его в набор качественных вирусных Shorts и длинных YouTube-компиляций, как у нарезчиков популярных стримеров.

# 7. SPEECH-TO-TEXT

Основная система распознавания:

WhisperX.

Официальный репозиторий:

https://github.com/m-bain/whisperX

WhisperX использовать вместо обычного Whisper там, где это дает преимущества.

Главные требования:

* русский язык;
* английский;
* автоматическое определение языка;
* timestamps;
* word-level timestamps;
* VAD;
* возможность diarization.

WhisperX должен сохранять результат в структурированный JSON.

Пример:

{
"language": "ru",
"segments": [
{
"start": 120.52,
"end": 124.81,
"text": "Это был невероятный момент",
"words": [
{
"word": "Это",
"start": 120.52,
"end": 120.80
},
{
"word": "был",
"start": 120.82,
"end": 121.10
}
]
}
]
}

Эти данные будут использоваться для:

* субтитров;
* анализа;
* поиска начала/конца клипов;
* удаления тишины;
* генерации текста;
* определения структуры разговора.

# 11. ПОИСК ИНТЕРЕСНЫХ МОМЕНТОВ

Затем более дорогой AI анализирует только candidates.

↓

↓

↓

LLM ANALYSIS

↓

Каждый потенциальный момент должен получить score.
