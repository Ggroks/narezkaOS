- [x] `config.yaml`: профили `dev`/`batch`/`auto`, `device: auto`, `degrade_gracefully`
- [x] Автоопределение устройства: torch → nvidia-smi → CPU, с явным переопределением
- [x] Интерфейс стадии: входы, выходы, требование к устройству, обязательность, срез конфигурации

- [x] Проверка окружения: `ffmpeg`/`ffprobe`/`yt-dlp`, устройство, ядра, RAM, свободное место
