# Запуск сервисом

Как открыть Narezka OS нескольким людям. Написано под выбранный сценарий:
**свой компьютер плюс туннель**, круг — пять-десять знакомых, оплата
кредитами.

Порядок здесь важен: пока не включён вход, наружу открывать нечего.

---

## 1. Включить вход и оплату

Настройки живут в `configs/config.yaml`. Для сервиса нужны четыре:

```yaml
auth:
  enabled: true          # без него сервис открыт всем, кто знает адрес
  secure_cookie: true    # ключ сессии только по https

billing:
  enabled: true          # счёт в кредитах и списания
  version: 1             # поднимайте при каждом изменении цен
  per_video_hour: {analysis: 20, shorts: 8, long: 12}
  minimum: 2
  signup_bonus: 60       # подарок вошедшему по приглашению

sources:
  allowed_hosts: [youtube.com, twitch.tv]   # пусто — любые публичные адреса

retention:
  source_days: 14        # через сколько дней убирать скачанные исходники
```

Проверить, что применилось: `narezka credits show --workspace default`
покажет цены и версию.

**Про цены.** Себестоимость часа записи — 15–20 ₽ по замерам, из них
примерно две трети приходится на запросы к модели. Кредит абстрактен:
сколько он стоит в деньгах, решает продажа, а не конфиг. Менять цены можно
свободно — каждое списание помнит версию, по которой посчитано, поэтому
история остаётся объяснимой.

---

## 2. Завести людей

```bash
narezka invite new --credits 100 --note "Вася"   # выдать код
narezka invite list                               # кто вошёл, кто ещё нет
narezka user add --login ivan --password ...      # или завести напрямую
narezka credits add --workspace ivan --amount 500 # пополнить счёт
narezka usage --days 30                           # сколько наработано
```

Регистрация закрыта кодом приглашения: код выдают одному человеку и можно
не выдать другому — настройка «регистрация открыта» такого не умеет.

---

## 3. Поднять сервис

**Прямо на машине** — так уже работает:

```bash
narezka serve --host 0.0.0.0 --port 8000
```

**Или в контейнере**, чтобы обновление не задевало систему:

```bash
docker compose up -d --build
docker compose logs -f narezka
```

Контейнер слушает только `127.0.0.1:8000`. Наружу его открывает туннель,
а не он сам.

---

## 4. Открыть доступ снаружи

Нужен туннель с сертификатом: пароли и ключи сессий по открытому http
ходить не должны. Подойдёт любой из привычных — Tailscale для круга своих,
Cloudflare Tunnel для публичного адреса. Домашний адрес при этом наружу
не светится, пробрасывать порты на роутере не требуется.

После этого проверьте главное:

- сайт открывается по `https://`, а не `http://`;
- без входа `/api/videos` отвечает 401;
- ссылка вида `http://127.0.0.1/...` при добавлении отклоняется;
- вкладка «Исходник» не начинает качать запись сама.

## Чего этот сервис пока не делает

Написано, чтобы не обнаружилось в неподходящий момент.

- **Приём платежей.** Счёт пополняется командой. Книга к платежам готова:
  когда они появятся, они будут писать те же самые записи.
- **Правовой слой.** При добавлении спрашивается подтверждение прав
  на запись, и ответ сохраняется с датой. Всё остальное —
  [docs/BACKLOG-legal.md](BACKLOG-legal.md): порядок по претензиям
  правообладателей, хранение чужих персональных данных (чат — это
  сообщения живых людей), правила пользования.
- **Рабочие машины отдельно от веба.** Обработка идёт в том же процессе.
  Пока предел параллельности — единица, это незаметно; при переезде на
  арендованное железо понадобится 9B.
- **Резервные копии.** Хранилище — обычный каталог, база в нём же.
  Копируется целиком, но никто этого не делает за вас.

## Что стоит помнить о нагрузке

Замеры на записи 4 ч 34 мин (6.59 ГБ):

| Что | Сколько |
|---|---|
| Машинное время | 45 мин на час записи (0.75 от реального) |
| Диск | 1.83 ГБ на час записи, из них 79% — исходник |
| Одна машина | около 700 часов записи в месяц |
| Трафик разметки | 7 МБ за сеанс — моменты режутся кусками |

Одна запись занимает машину примерно на два с половиной часа. Поэтому
задачи стоят в очереди по одной, а у каждого владельца одновременно
выполняется не больше одной — иначе человек с десятью записями занял бы
машину на полсуток.
