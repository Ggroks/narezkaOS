# Шрифты субтитров

**Зачем.** Субтитры вшиваются в кадр через libass ([§18](../../BAZA.md#18), [§60](../../BAZA.md#60)). Шрифт определяет, как ролик выглядит, и — на кириллице — читается ли он вообще.

**Какую проблему решает.** До этого стиль называл шрифт по имени семейства, а искал его fontconfig на той машине, где идёт рендер. Отсюда два отказа, оба тихие:

- на другой машине того же семейства может не быть, libass подставит ближайшее найденное — и тот же материал с той же настройкой выйдет другим роликом. Это прямо ломает требование [§62](../../BAZA.md#62) о работе на разных компьютерах;
- подстановка может не содержать кириллицы, и вместо текста получаются пустые прямоугольники. Видно это только на готовом видео, когда время рендера уже потрачено.

**Что используется.** DejaVu Sans (обычное и полужирное) и DejaVu Serif лежат в `assets/fonts` вместе с лицензией. libass получает каталог параметром `fontsdir` и берёт шрифты оттуда, а не из системы.

**Лицензия.** Bitstream Vera Fonts License — разрешает использование, копирование, изменение и распространение, в том числе в коммерческом продукте. Требует прикладывать текст лицензии к копиям (`assets/fonts/LICENSE.txt`) и запрещает продавать сами шрифты отдельно от продукта. При изменении начертаний шрифт нужно переименовать так, чтобы имя не содержало «Bitstream» или «Vera».

**Железо и скорость.** Влияния нет: шрифт растеризуется на CPU, доля в общем времени рендера незаметна.

**Размер в репозитории.** 1.8 МБ на три файла. Это плата за одинаковый результат на любой машине.

**Чем заменить.** Любым шрифтом с лицензией, разрешающей распространение: Noto Sans, Liberation Sans, Inter — все под SIL OFL 1.1. Порядок замены: положить файлы в `assets/fonts`, добавить семейство в `FONT_FILES` в [narezka/core/fonts.py](../../narezka/core/fonts.py), указать его в пресете стиля. Имя семейства должно совпадать с тем, что записано внутри самого файла шрифта, иначе libass его не найдёт.

**Как проверить.** `narezka doctor` показывает строку «шрифты субтитров»; она критическая, потому что без шрифтов рендер даёт нечитаемый результат, а не ошибку. Что libass взял на самом деле, видно в подробном логе:

```
ffmpeg -v verbose ... -filter_complex "...subtitles=00.ass:fontsdir=assets/fonts..."
# Loading font file '.../assets/fonts/DejaVuSans.ttf'
```
