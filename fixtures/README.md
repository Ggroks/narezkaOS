# Фикстуры

Короткие нарезки реальных стримов для цикла разработки на CPU (BAZA.md §62).

Что нужно:

- 2–3 файла по **5–10 минут** — на этом железе `base` укладывается в 2–3 минуты;
- живая русская речь: без неё нельзя проверить ни качество распознавания,
  ни фильтр галлюцинаций (§57);
- желательно с музыкой на фоне — именно там Whisper начинает выдумывать текст;
- рядом заметка с таймкодами заведомо интересных моментов: это станет
  первой проверкой качества отбора (§53, приоритет №1).

Сами файлы в репозиторий не попадают — см. `.gitignore`.

Добавить в обработку:

```bash
.venv/bin/narezka add --file fixtures/stream1.mp4
```

Либо через интерфейс: поле «путь к локальному файлу» на главной странице.
